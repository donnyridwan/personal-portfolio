# Admin CMS Dockfolio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pindahkan situs statis ke aplikasi Next.js 16 yang membaca isi Finder dari Neon dan menyediakan `/admin` (satu password) untuk mengelola proyek, kategori, featured, dan profil, dengan upload langsung ke Cloudinary.

**Architecture:** Situs Framer + Finder dipindah apa adanya ke `public/`; `/` di-rewrite ke `/index.html`. `GET /api/finder` membaca tabel `categories`, `projects`, `settings` lalu menyusunnya lewat fungsi murni `lib/finder-data.ts` ke bentuk `finder-data.json`. Admin = Server Components + Server Actions; `proxy.ts` (nama baru `middleware.ts` di Next 16) mengalihkan `/admin/*` tanpa cookie valid, dan setiap Server Action/route admin mengecek cookie sendiri. Upload: browser minta signature ke `POST /api/admin/cloudinary-signature`, lalu kirim file langsung ke Cloudinary.

**Tech Stack:** Next.js 16 (App Router, TypeScript), npm, `@neondatabase/serverless`, Vitest, `node --test` (tes model Finder lama), CSS biasa.

**Spec:** `docs/superpowers/specs/2026-11-16-admin-cms-design.md`

## Global Constraints

- Isi ekspor Framer (`index.html`, `assets/`, `f2c-sw.js`) tidak diedit; hanya dipindah ke `public/`.
- `/` tetap situs Framer (rewrite ke `/index.html`); tidak ada `app/page.tsx`.
- `/api/finder` tidak di-cache: `export const dynamic = 'force-dynamic'`.
- Kredensial (`DATABASE_URL`, `ADMIN_PASSWORD`, `CLOUDINARY_URL`) hanya dibaca di server; tidak pernah ada di bundle client atau respons API.
- Cookie admin: nama `dockfolio_admin`, isi hex SHA-256 dari `ADMIN_PASSWORD`, `httpOnly`, `sameSite=lax`, `path=/`, `maxAge` 30 hari, `secure` saat production.
- Pesan error Finder persis: "Data belum bisa dimuat. Coba lagi." dengan tombol "Coba lagi".
- Warna featured preset: `#ff5f57`, `#febc2e`, `#ffd60a`, `#28c840`, `#0a84ff`, `#bf5af2`, `#8e8e93`.
- Folder Cloudinary: `dockfolio/projects/<id>` dan `dockfolio/profile`. Batas file 10 MB; gambar jpg/png/webp/gif, resume PDF.
- Gaya admin: font sistem, aksen `#0a64ff`, CSS biasa, tanpa library UI. Teks UI berbahasa Indonesia.
- Database sudah di-seed — **jangan** jalankan ulang `db/seed.sql`. `db/seed.ts` di spec tidak dibuat (YAGNI: seed sudah dijalankan dari `seed.sql`).

## Review Focus

1. Database Neon sedang bangun/lambat atau `DATABASE_URL` kosong → `/api/finder` balas 500 JSON `{error}`; Finder menampilkan pesan error + tombol Coba lagi, bukan jendela kosong; klik Coba lagi mengambil ulang. (Task 4 — tes manual curl + `finder-model` tetap lulus.)
2. Proyek memakai id kategori yang sudah dihapus, featured tanpa urutan, kolom null → output tetap valid menurut `validateData`. (Task 2 — tes Vitest.)
3. Cookie palsu / password salah / `ADMIN_PASSWORD` kosong → semua route admin dan Server Action menolak; login dengan password kosong tidak pernah lolos meski env kosong. (Task 3 — tes Vitest `lib/auth`.)
4. Nama proyek berkarakter khusus ("BRND™", spasi ganda, huruf beraksen) → slug id aman dan unik; bentrok id ditolak dengan pesan. (Task 5 — tes Vitest `slugify`.)
5. Upload file > 10 MB atau tipe salah → ditolak di browser sebelum dikirim; signature hanya menandatangani folder yang diizinkan. (Task 6 — tes Vitest `signParams` + cek manual.)
